# GalaSMP Mods (Fabric 1.21.11)

- **OreGlow** – Leucht-Texturen fuer jedes Erz einzeln an/aus. Taste **O** oder Mod Menu.
- **OrderAlert** – Meldung (Enderdrachen-Sound, Popup, Chat), wenn auf HugoSMP ein Item ab deinem Preis pro Stueck geordert wird – auch bei geschlossenem Menue (alle 15 Sekunden).
  Taste **J**: Preis eingeben, Item waehlen. Alternativ `/orderalert add <Mindestpreis> <Item>`.
- **VideoWindow** – Video-Fenster mit Ton (YouTube, Twitch, Kick, Video-Links) direkt im Spiel.
  Taste **B** oder `/video <Link>`. Bei offenem Chat (**T**) mit der Maus verschieben (Titelleiste),
  an den Ecken groesser/kleiner (Seitenverhaeltnis bleibt), an den Seiten nur breiter/hoeher.
  Braucht zusaetzlich **WaterMedia** (liegt im Release mit dabei) und **WaterMedia Binaries** (Modrinth).
  Optional: **MCEF Modern** fuer normale Webseiten.

Die fertigen JARs stehen unter **Releases**. Beide brauchen die Fabric API.
